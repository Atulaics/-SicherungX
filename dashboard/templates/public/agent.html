How It Works

1

Install & Run

Download the `.exe` and run it on any employee workstation. No complex network configuration needed.

2

Secure Login

The employee logs in using their Email/ID. The agent automatically captures the device ID, OS info, and binds the device to their profile.

3

Silent Monitoring

The GUI closes and monitoring begins in the background. It continuously streams analytics to the central AI server.
